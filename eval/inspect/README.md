# UK AISI `Inspect AI` Harness (`eval/inspect/`)

Canonical [**UK AISI Inspect AI**](https://inspect.aisi.org.uk/) evaluation harness for the **Evergreen Insurance API Gym** ([`DECISIONS.md`](../../DECISIONS.md), ADR-005). Both [`evergreen.py`](evergreen.py) (`@task def evergreen`) and [`evergreen_langchain.py`](evergreen_langchain.py) (`@task def evergreen_langchain`) execute one standard LangChain agent (`create_agent` over `ChatOpenAI(model="inspect")`) through Inspect's `agent_bridge`, so every model runs through the exact same typed-tool loop while Inspect tracks trials, token counts, turn limits, and `.eval` transcripts.

---

## 1. Typed 3-Modality Tooling (No Shell, No Generic HTTP)

- **REST (`56` typed tools):** One tool per operation in `specs/ams.yaml` (`19`), `rater.yaml` (`6`), `crm.yaml` (`9`), `ecm.yaml` (`13`), and `claims.yaml` (`9`), generated by [`openapi_tools.py`](openapi_tools.py). Path and query parameters are top-level arguments and request payloads pass via `body`. A client-credentials OAuth token (`agent-full`) from AMS is cached and attached automatically.
- **Messaging Hub (`comm` MCP):** Streamable HTTP MCP tools (`get_inbox`, `send_message`, `get_transcript`, `manage_webhook`) at `/mcp` on `:3004`, authenticated with an AMS OAuth Bearer token.
- **Carrier Portals (`portals` MCP):** Playwright MCP (`@playwright/mcp@0.0.85`) over `stdio` with headless Chrome, an isolated profile, and `--allowed-origins` restricted to Summit Fire (`:3005`) and Coastal Star (`:3006`). `browser_evaluate` and `browser_run_code_unsafe` are stripped so arbitrary JS/HTTP execution is impossible.
- **Learning Mechanisms (`-T learning_mechanism=none|domain_skill`):** Compare zero-shot (`None (zero-shot)`) against the scenario-agnostic agency CSR SOP ([`evergreen_domain_skill.md`](evergreen_domain_skill.md), `Domain skill (SOP)`).

## 2. Setup & Single-Command Execution

```bash
pip install -r eval/inspect/requirements.txt   # Python 3.10+ virtualenv
bun run showcase --strict                      # launches all 8 services on :3000-:3007
```

```bash
# Run tasks via evergreen.py (or evergreen_langchain.py):
inspect eval eval/inspect/evergreen.py \
  --model google/gemini-3.8-flash \
  -T scenario=08,19 \
  -T seed=realistic \
  -T difficulty=natural \
  -T modality_mode=strict \
  -T learning_mechanism=domain_skill \
  --max-samples 1

# Run pure DB-state multi-turn deterministic scenarios (eval/deterministic/*.yaml):
inspect eval eval/inspect/evergreen_deterministic.py \
  --model google/gemini-3.8-flash \
  -T scenario=DT-01,DT-02,DT-03,DT-04,DT-05 \
  --max-samples 1

# Run the 3-model Vertex AI baseline across 4 isolated parallel service stacks (:3100..:3400):
python3 eval/inspect/run_baseline.py \
  --scenario all \
  --difficulty natural \
  --epochs 5 \
  --parallel-stacks 4 \
  --with-clean \
  --artifacts-dir eval/results/v0.8/artifacts \
  --out-dir eval/results/v0.8

# Regenerate the README Results table (defaults to eval/results/v0.8/realistic-natural, falling back to v0.7):
python3 eval/inspect/summarize_inspect.py --include-anchors

# Summarize deterministic DB-state runs and emit a SHA-256 replay manifest:
python3 eval/inspect/summarize_deterministic.py eval/results/deterministic-v1/logs \
  --artifacts-dir eval/results/deterministic-v1/artifacts \
  --md-out eval/results/deterministic-v1/summary.md \
  --json-out eval/results/deterministic-v1/summary-report.json \
  --export-replay-manifest eval/results/deterministic-v1/replay-manifest.json
```

## 3. Replayable Receipt Bundles & Tests

When `-T artifacts_dir=<dir>` (or `EVERGREEN_ARTIFACTS_DIR`) is provided, each trial archives `trace.json`, `snapshot-before.json`, `snapshot-after.json`, `<scenario_id>-report.json`, and `sha256sums.txt` under `<artifacts_dir>/<model_slug>/<seed>-<difficulty>/<sample_id>-e<epoch>/` and records the portable repo-relative path in `Score.metadata["artifacts_dir"]`. Use `summarize_inspect.py --export-replay-manifest <file>` to emit a complete per-trial SHA-256 manifest.

```bash
pytest eval/inspect/tests
```
